网络拓扑

按 WAN → 上级 LAN 自动推断层级
说明
每个节点是一张卡片：左侧为设备信息与上行链路（介质 / 端口 / 协商速率 / 上级节点），右侧按有线 · 2.4G · 5G 分道列出下挂终端。卡片到终端的实际接线：卡片右侧引出一条总线，总线上按介质分出支路，每台终端再从自己的介质端口上接出一小段——所以看线就知道谁接在哪、走的什么介质；节点之间的连线用流动光点表示层级方向。只有安装本插件的节点才能采集无线关联、信号、频段与协商速率。普通硬路由：桥接 / AP 模式下，上级 DHCP、ARP 只能看到其下终端的 IP/MAC/主机名，看不到连在哪个 AP 及无线详情；路由 / NAT 模式下，上游只能看到硬路由自身一个 MAC，其下设备完全不可见。可在 /etc/config/opshare 用 config external 手工声明，拓扑图会画成灰色虚线节点。
零配置配对：两台都装好本插件后，各自会在两分钟内探测默认网关与最新 DHCP 租约，用 HTTP 交换身份与共享密钥自动配对——不需要填 IP、不需要授权 SSH 密钥，桥接与双 NAT 都适用。CPU 更强的一台自动当聚合者，另一台被动接收；在 /etc/config/opshare 里设 option auto_pair 0 可改为手工管理。
有线链路 2.4G 无线回程 5G 无线回程 拨号 / 未知 在线 离线 点击终端定位到列表（不改筛选），点击节点卡片定位到节点详情
角色是完全自由的标签，拓扑不决定主从：自动判定只给建议，可在每个节点卡片上自由设置

接口流量

接口累计总量 · 相邻快照增量
说明
每个接口两行：上行（上传）在上、下行（下载）在下，左边是该接口的累计字节，右边是相对上一次快照的增量。不计算速率、不画曲线、不保存历史。计数器重置、设备重启或时钟跳变会标注并跳过该次增量；开启硬件加速/流量卸载时计数可能偏低。
